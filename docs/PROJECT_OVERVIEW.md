# CineIELTS — Project overview

## The learning problem

Learners often move between separate resources for vocabulary, authentic expressions, exam practice and feedback. CineIELTS connects these activities within a single study environment.

## A typical workflow

1. Choose a study goal or follow a learning plan.
2. Explore useful expressions and ideas through scene-based material.
3. Practise a related listening, reading, writing or speaking task.
4. Use the available AI feedback to reflect on an answer or revise it.
5. Save expressions, revisit mistakes and review learning records.

This is an overview of the product workflow; access to specific features can vary by edition, account and service availability.

## Engineering work

- Product flow and responsive learner interfaces.
- React/TypeScript frontend and Python/FastAPI backend integration.
- AI coaching, writing feedback and optional speech capabilities.
- Study records, vocabulary and personal learning resources.
- Deployment and iteration across China and international editions.
